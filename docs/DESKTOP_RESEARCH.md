“Documented” means the official source describes the capability. No independent feature absence or failure was established. The Documint on-premise statement is explicitly vendor-documented. Where a capability is **not verified**, it must not be marketed as a competitor limitation. Hosted API dependencies describe those vendors' documented workflows, not every possible deployment option. Competitor prices are not converted to NGN and are not BGM price recommendations.

BGM's proposed opportunity is a bursary-focused, offline workflow with curated templates, validated source imports, branded output, transparent exceptions, retained revisions and retrieval/recovery. Whether institutions value these enough to buy requires customer interviews and an authorised pilot; worldwide uniqueness is not claimed. Do not call this a complete accounting system.

## Engineering references

Reviewed [Electron distribution](https://www.electronjs.org/docs/latest/tutorial/distribution-overview), [security](https://www.electronjs.org/docs/latest/tutorial/security), [PDF printing API](https://www.electronjs.org/docs/latest/api/web-contents), [Electron licence](https://www.electronjs.org/docs/latest/why-electron), [PDF.js project materials](https://mozilla.github.io/pdf.js/getting_started/) and [Node SQLite](https://nodejs.org/api/sqlite.html). Electron is described by its official site as MIT-licensed and commercially usable. PDF.js uses Apache-2.0 and is a development dependency excluded by the explicit Electron app file allowlist. The Windows installer bundles Electron, including Chromium/Node runtime components and notices; a release-specific third-party notice inventory inside the final installer still needs completion. `electron-builder` is build-time tooling and excluded from the application file allowlist. These docs support the implementation choice and APIs but do not prove this application's installation/security acceptance. Native versions are recorded in ignored acceptance evidence.

Code signing is waived by the owner for this unsigned pilot. No certificate is purchased or represented as required; future release signing remains a separate security and trust decision. Do not tell customers to bypass Windows or antivirus warnings.
