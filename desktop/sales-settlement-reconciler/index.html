Important limits

This is a standalone Windows desktop utility, not an Excel add-in. It reads and writes .xlsx files locally; it does not log into a bank or payment provider. Import values are treated as data, formulas are never executed, and source files are not edited. Numeric IDs whose leading zeros were already discarded by the source application cannot be reconstructed unless a zero-padding number format was saved with the cell.

Use the result as an accountant’s review aid. It does not post entries, certify accounts, or replace professional review.
