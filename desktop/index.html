Recorded officer

Enter the name used for this session before saving setup or reviewing records. These are local workflow labels, not authenticated identities.

01 / Institution setup

Configuration is captured when a draft is created. Final documents retain their original branding.

Logo import and signature images are not implemented. Manual signature blocks only.

02 / Validate and accept imports

CSV only in this pilot. Exact headers: reference, student, name, date, currency, amount, kind, evidence. Use ISO dates and decimal text. References are institution-wide unique; student is the account/payee text ID.

No bank is contacted. Acceptance records your review of the source, not an independent audit.

03 / Documents and retrieval

Choose one payment per receipt. Statements require the complete selected account period; verify the selection and opening balance before review. Named officer controls are local workflow records, not authenticated identities.

04 / Durable PDF jobs

Review each draft before queueing. Each document is an independent durable job. Interrupted jobs resume on restart. Numbering gaps are retained and explained by history.

05 / Backup, export and licence

Backups contain sensitive records and PDFs. Use a unique passphrase of at least 12 characters. There is no password recovery. Keep a separate offline copy. Restore is allowed only into an empty profile.

Plain JSON exports are unencrypted. This pilot has no activation server or automatic update installer. Expiry preserves historical exports. Local administrators can bypass application controls; records are not tamper-proof. Never keep the SQLite profile on a shared/network drive.
